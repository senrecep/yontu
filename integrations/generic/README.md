# Any other agent

`AGENTS.md` here is a condensed version of the skill for agents that read `AGENTS.md` (Codex, Cursor, Windsurf, Zed, Antigravity, Copilot and others) but not skill folders. Paste it into your project's `AGENTS.md`. It refers to the full skill, the MCP server and the CLI when they are available and works without them.

For the MCP server, any stdio client works: the command is `yontu mcp` (or `python3 /path/to/yontu/skills/yontu/scripts/yontu mcp`).
