# Research notes

Dated background notes written while the rules were drafted. They are not rule sources: they hold candidate patterns, examples and open questions, and some of it was never verified or was later changed.

The rules themselves live in `skills/yontu/scripts/yontu/data/`, and the guidance for agents lives in `skills/yontu/references/`. Each rule's `source` field says what it rests on. Run `yontu explain <ID>` to see it.
